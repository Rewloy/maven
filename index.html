Rewloy Maven

https://maven.rewloy.com

Rewloy istemci kütüphanelerinin Maven deposu. Burada yalnız yayımlanmış paketler durur; kaynak kodu Rewloy/rewloy-kotlin deposundadır. Yeni sürümleri o deponun Release iş akışı ekler; yayımlanmış bir sürüm sonradan değişmez.

The Maven repository of the Rewloy client libraries. It holds published packages only; the source is in Rewloy/rewloy-kotlin, whose Release workflow adds each new version. A published version never changes afterwards.

Gradle (Kotlin DSL)

Android Studio: repositories, settings.gradle.kts içinde dependencyResolutionManagement altına yazılır. In Android Studio the repositories go in settings.gradle.kts, inside dependencyResolutionManagement.

repositories {
    mavenCentral()
    maven("https://maven.rewloy.com") {
        content { includeGroup("com.rewloy") }
    }
}

dependencies {
    implementation("com.rewloy:rewloy:0.2.3")
    implementation("com.rewloy:rewloy-okhttp:0.2.3")      // optional
    implementation("com.rewloy:rewloy-coroutines:0.2.3")  // optional
}

Gradle (Groovy)

repositories {
    mavenCentral()
    maven {
        url = 'https://maven.rewloy.com'
